Web-based mapping tool

01 Overview

Why the tool exists

The extreme-environment exploration mission is the core of the two-hour modular robotics programme I led for high-school students.

Developing the mapping program was part of the full process I handled, alongside planning, robot selection, obstacle design and map layout. The result is a web-based tool that collects mission data and visualizes it in real time during the mission.

02 What it does

Collect, visualize, in real time

  • 01

    Real-time collection

    Mission data is collected while the mission runs.

  • 02

    Visualization

    The collected mission data is visualized in real time.

  • 03

    Web stack

    Built with JavaScript, HTML and CSS on Firebase Realtime Database.
